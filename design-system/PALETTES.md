# Palettes

Six palettes, each with a light and a dark variant. Every variant sets the same tokens, so a page written against `var(--…)` works in all twelve. Switch with `<html data-palette="<id>" data-mode="light|dark">` (`Playground.setTheme` does it). Catppuccin is the default.

## Notes

- `--accent-ink` is `#ffffff` in light variants and the variant's `--bg` in dark ones.
- In Rosé Pine, acid–base is blue-teal (pine / foam) because the palette has no true green.
- `--cond` (condensation / hydrolysis) is each palette's own seventh hue: Catppuccin pink, Tokyo Night cyan, Nord frost, Rosé Pine rose, Gruvbox aqua, Everforest orange.
- Dark variants: `--hl` rgba(255,255,255,.09), `--shadow` rgba(0,0,0,.38), `--sheen` rgba(255,255,255,.05). Light variants: `--hl` .75, `--shadow` = `--ink` at 15%, `--sheen` .55.
