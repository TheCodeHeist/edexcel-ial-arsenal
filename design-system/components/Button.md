# Button

Pill buttons: a neutral glass default and one accent primary per area.

- `.btn` — `--raised` fill, `--rim` border, inset `--hl`; Geist 13px 700. `.btn.primary` — `--accent` fill, `--accent-ink` text and the primary glow.
- Press scales to .96 with the spring; hover lifts 1px only where hover exists; `:disabled` drops to 45% opacity.
- One primary per panel (New target, Next). Focus ring: 2px `--accent`, 2px offset.
